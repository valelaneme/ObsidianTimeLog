# 时间日志（TimeLog）

一个只做三件事的安卓小工具：把时间记录追加到 Obsidian 每日 md、校验时间重叠、做日/周/月/年分析。没有编辑器、没有同步、没有账号。

## 它认什么格式

文件名必须是日期，例如 `2026-11-19.md`。文件里只认这种行：

```
- [ ] ==00:00 - 05:30== [[○ 睡觉]] [[♺ 晚睡]] **-** 昨天睡的很早，感觉起来还是不精神。
- [ ] ==05:30 - 06:10== [[○ 家务]] [[♺ 做饭]] **早餐** 做了什么 [[地点]]  [[任务]]
```

规则：以 `- [ ]` 或 `- [x]` 开头；时间段写在 `== ==` 里；`[[○ 分类]]` 是一级，`[[♺ 分类]]` 是二级；`**事项**` 里写 `-` 表示没有事项名。其他文字当备注，`[[地点]]` 这类链接只存不算。

## 三个口径（已按你的要求写死在代码里）

1. **睡眠计入统计**：总时长和分类占比都包含睡眠，不剔除。
2. **跨午夜按实际时间切两天**：例如 `23:00 - 01:00`，当天记 `23:00-24:00`，次日 md 记 `00:00-01:00`。
3. **覆盖率含睡眠**：覆盖率 = 区间内记录总分钟 ÷（天数 × 24 × 60）。所以一天记满才 100%。

## 怎么用（手机上）

1. 打开 App，点 **选择日记文件夹**，选中你的 Obsidian 日记目录（就是放 `2026-11-19.md` 的那个文件夹）。允许访问。
2. 点 **重新读取**，会提示读到多少条。
3. **录入** 页：填日期、起止时间、一级/二级分类、事项、备注，下方预览就是将要写入的那一行，点"生成并追加到当天 md"。
4. **校验** 页：列出所有重叠的区间，含重叠分钟数。
5. **分析** 页：点 日/周/月/年 切换，用 ‹ › 翻到上一个/下一个周期。显示总时长、覆盖率、一级/二级分类占比。

录入这一步也可以继续用你现有的 MacroDroid，App 只用来校验和分析——两套写入的格式一致即可。

## 怎么打包安装（你会 fork 和签名，这里只列关键点）

1. 用 Android Studio 打开 `TimeLog` 文件夹（File → Open），等 Gradle 同步完成。
2. 手机开开发者选项 + USB 调试，数据线连上，点运行（▶）可直接装到手机验证。
3. 打包：Build → Generate Signed Bundle / APK → APK → 选你已有的 keystore → 生成 release APK。
4. 把 APK 传到手机安装。首次打开需要选一次文件夹授权。

最低支持 Android 8.0（API 26）。

## 已知限制与风险

- **当前环境没有 Android SDK，无法本地编译**。代码已做静态检查（括号配平、控件 ID 对齐、解析规则用真实日志样例验证通过），但首次在 Android Studio 同步/编译时仍可能有环境相关问题。若报错，把红色报错原文复制给 Gemini 或发给我即可定位。
- Gradle 插件版本：AGP 8.2.2 / Kotlin 1.9.22 / Gradle 8.2，compileSdk 34。若你的 Android Studio 较新提示升级，按提示升级即可。
- `minSdk 26`：Java 8 时间 API（java.time）在 26 以上可用，低于此版本不支持。
- 只扫描所选文件夹**第一层**的 `.md` 文件，不递归子目录。如果你的日记按月份分子文件夹，需要把日记平铺到一个目录，或告诉我改成递归。
- 覆盖率分母固定是全天 24 小时，睡多久都算进分子；这是你指定的口径。
- 二级分类如果留空，分析里归入"（未填二级）"。
