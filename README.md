# 时间日志（TimeLog）

一个极简安卓录入器：把时间记录快速追加到 Obsidian 每日 md、保存前校验重叠、看当天统计。数据始终是你的 md 文件，不锁在 App 里。

> 📌 完整设计（含未来周/月/年方案、冷热数据、快照）见 [DESIGN.md](DESIGN.md)。本 README 只描述**当前代码实现了什么**。

## 当前版本（v1 · 单日版）

**界面**：打开就是**当日分析首页**（昨天/今天随便翻）。屏幕**底部固定三个大按钮**，单手握手机拇指就够得到：

| 按钮 | 作用 |
|---|---|
| ⏱ 正计时 | 点一下开始（记住开始时刻），忙完再点一下 → 时间段自动填进录入框。**锁屏、切到微信都不影响**，因为记的是时间点不是累加秒数。 |
| ✎ 录入 | 从底部弹出一个**最多半屏的录入面板**，浮在分析页上；下滑顶部的把手或点 × 或点面板外都能收起。 |
| ⏳ 倒计时 | 输入分钟数 → 到点**弹手机通知**，关掉 App、锁屏也照弹。点通知会回填时间段。 |

**保存前校验**：点"校验并追加"时，先检查新时间段和当天已有记录是否重叠。有重叠弹窗告诉你和哪条重叠、多少分钟，你可以**返回改时间**或选择**仍然保存**——不会再默默写进一条冲突记录。

**录入提速**：日期默认当天；起止时间旁有"现在"一键填当前时刻；一级/二级分类、事项、双链记住上次填过的；边填边预览要写入的那一行。

**跨午夜**：结束早于开始时按 24 点拆成两行写进两天（如 `23:50-24:00` + 次日 `00:00-00:20`）；结束正好 00:00 只写当天一段。

**单日统计**：当天总时长（含睡眠）、覆盖率（分母 24 小时）、一级/二级分类时长占比。点 ‹ › 翻任意一天。首页内嵌显示当天重叠。

**周 / 月 / 年分析**：后续版本加入。底层已把"单日小计"做成可聚合的数据原子，加周/月分析不用改录入和解析代码。

## 它认什么格式

文件名必须是日期，例如 `2026-11-19.md`。文件里只认这种行：

```
- [ ] ==00:00 - 05:30== [[○ 睡觉]] [[♺ 晚睡]] **-** 昨天睡的很早，感觉起来还是不精神。
- [ ] ==05:30 - 06:10== [[○ 家务]] [[♺ 做饭]] **早餐** 做了什么 [[地点]]  [[任务]]
```

规则：以 `- [ ]` 或 `- [x]` 开头；时间段写在 `== ==` 里；`[[○ 分类]]` 是一级，`[[♺ 分类]]` 是二级；`**事项**` 里写 `-` 表示没有事项名。其他文字当备注，`[[地点]]` 这类链接只存不算。

## 三个口径（写死在代码里）

1. **睡眠计入统计**：总时长和分类占比都包含睡眠，不剔除。
2. **跨午夜按实际时间切两天**：例如 `23:00 - 01:00`，当天记 `23:00-24:00`，次日 md 记 `00:00-01:00`。
3. **覆盖率含睡眠**：覆盖率 = 记录总分钟 ÷（天数 × 24 × 60）。一天记满才 100%。

## 怎么用（手机上）

1. 打开 App，点 **选择日记文件夹**，选中 Obsidian 日记目录（放 `2026-11-19.md` 的那个文件夹），允许访问。首次会问通知权限，选允许（倒计时要用）。
2. 首页看当天统计；点 ‹ › 翻日期。
3. 记录一段：点 **正计时** 开始 → 忙完再点一下 → 点 **录入** 弹出面板，时间段已填好 → 补分类/事项 → 点"校验并追加"。有重叠会弹窗让你确认。
4. 或直接点 **录入** 手动填；点起止旁的"现在"填当前时刻。
5. 定时一段：点 **倒计时** 输分钟数 → 到点通知 → 点通知回填时间段。再点倒计时按钮可取消。

录入这一步也可以继续用你现有的 MacroDroid，App 只用来计时和校验——两套写入格式一致即可。

## 代码结构（便于以后加功能）

```
core/   纯 Kotlin，不依赖 Android，可单独测试
  Models.kt       数据模型，核心是 DaySummary（单日小计，可聚合）
  LogParser.kt    把 md 一行解析成 LogEntry（跨午夜拆两天）
  LogFormatter.kt 把录入字段拼成 md 行（与 Parser 严格对称）
  Analyzer.kt     analyzeDay(单日) + combine(聚合，供周/月/年用) + overlaps(校验)
data/   Android 数据层
  VaultRepository.kt  SAF 授权、loadDay(只读当天，秒开)、追加写入
  Prefs.kt            记住上次录入 + 计时状态（存绝对时刻，切走也准）
MainActivity.kt   只做 UI 编排：首页/三按钮/浮层/校验弹窗/计时
TimerReceiver.kt  倒计时到点的系统闹钟接收器，弹通知
```

加周/月分析时：读那几天的 DaySummary，调用 `Analyzer.combine()` 聚合即可，不需要新的分析逻辑。

## 怎么打包安装（本机没有 Android Studio，用 GitHub 云端编译）

1. 把代码传到 GitHub（网页版新建仓库 → upload files → 拖进去 → Commit changes）。
2. 点 **Actions** → 左侧 **Build APK** → **Run workflow** → 点绿色按钮。
3. 跑完点进这次运行 → 最下方 **Artifacts** → 下载 **TimeLog-APK**（zip）→ 解压得到 `app-debug.apk`。
4. APK 传到手机安装（允许"安装未知来源应用"）。首次打开选一次日记文件夹授权 + 通知权限。

每次云端编译版本号自动 +1。APK 用默认调试签名可直接装；换正式签名需配 GitHub Secrets（以后需要再加）。最低 Android 8.0（API 26）。

## 已知限制与风险

- **本机没有 Android SDK，无法实编译**。代码已做静态检查（括号配平、控件 ID 与代码引用完全对齐、无旧符号残留、权限声明一致），并用真实数据验证过"生成→解析→聚合""保存前重叠校验"全链路。GitHub Actions 首次运行若报错，把红色日志原文发我即可定位。
- **精确闹钟**：Android 14+ 把"精确定时"列为特殊权限，需你在系统设置里给本 App 开一下"闹钟和提醒"；不开也能响，只是可能晚几分钟（代码会自动降级）。红米若省电策略拦截，把本 App 设为"无限制"。
- **通知权限**：Android 13+ 首次会问；拒绝后倒计时到点不弹通知，需在系统设置里补开。
- 日历只读当天对应的 md（加前一天跨午夜落到当天的一条），**不递归子目录**。按年归档进子文件夹的旧日志当前读不到——这正是 DESIGN.md 冷热分层方案要解决的，后续版本实现。
- 二级分类留空时，统计归入"（未填二级）"。
